v2.2.0 可以開啟與搜尋神隱漫畫，Windows 版也改成在 App 內自動覆蓋更新。

- 神隱漫畫可以開啟了：原本顯示「漫畫不存在」的作品，現在能看詳情、完整章節列表與評論；沒有閱讀權限時，會說明是需要登入還是等級不足。（#2）
- 搜尋會補上官方搜尋找不到的神隱、下架作品，資料來自每日更新的本地漫畫索引，可以在「我的 → 更多設定 → 漫畫」關閉或手動更新。（#1）
- Windows 版 App 內更新改為自動覆蓋安裝：下載後核對 GitHub 公布的檔案雜湊，App 關閉後自動換成新版並重新開啟，任何一步失敗都會保留原本的版本；網路中斷時會從斷點續傳。安裝在無法寫入的位置（例如 C:\Program Files）時，維持下載壓縮檔。
- 其他小幅調整與穩定性改善。

安裝包內建本地漫畫索引，因此大約增加 2.7 MB。

Android 可從 App 內檢查更新，或下載 `ZAI-X-android.apk` 覆蓋安裝。Windows 這一次仍要手動更新：先關閉舊版，把 `ZAI-X-windows-x64.zip` 解壓到原本的資料夾覆蓋舊檔，再執行 `ZAI-X.exe`；從 v2.2.0 開始，之後的版本就能在 App 內自動更新。既有資料、名稱與圖示沿用原設定。
